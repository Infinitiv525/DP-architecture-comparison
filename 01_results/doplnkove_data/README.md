# Doplnkové vedecké dáta

[Stiahnuť doplnkový balík](https://github.com/Infinitiv525/DP-architecture-comparison/releases/tag/scientific-data-supplement-20261118). Tento balík rozširuje pôvodné archívy o ďalšie surové merania, číselné série, zdrojové kontrolné súčty, konfigurácie a dostupné technické záznamy.

Počet pridaných súborov: 288. Nezbalená veľkosť: 1881304 B.

Váhy a pôvodné výsledky sa nemenili. Každý súbor má pôvodnú cestu a SHA256 v manifeste; všetky archívy boli overené pred odoslaním aj úplným spätným prečítaním na Perune. Dáta nešli cez PC.

Veľké referenčné a predikčné polia sa inventarizujú osobitne; tento doplnok zatiaľ nie je úplným zrkadlom disku Perunu. Externé FlowBench vstupy a pôvodné LLM sa získavajú z pripnutých pôvodných zdrojov.
